# Traffic Violation Detection Pipeline

This project implements a complete pipeline for traffic violation detection, including helmet detection and license plate recognition.

## Project Structure
- `configs/`: Configuration files
- `models/`: Downloaded and trained models
- `datasets/`: Training and validation datasets
- `train/`: Training scripts
- `evaluation/`: Evaluation scripts
- `visualizations/`: Visualization scripts and notebooks
- `outputs/`: Outputs (logs, inference results, evaluation results)
- `utils/`: Utility scripts (logger, benchmarks, etc.)

## Setup
1. Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the inference pipeline: `python solution.py`
